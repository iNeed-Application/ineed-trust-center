# iNeed Trust Center

Public legal-information website for iNeed social authentication and account services.

## Published routes

- `/privacy-policy.html`
- `/data-deletion.html`
- `/terms-of-service.html`
- `/contact.html`

## Meta configuration

Use these URLs after GitHub Pages reports a successful deployment:

```text
Privacy Policy URL:
https://ineed-application.github.io/springboot-main-app/privacy-policy.html

User Data Deletion URL:
https://ineed-application.github.io/springboot-main-app/data-deletion.html
```

The application icon prepared for Meta is `assets/ineed-app-icon-1024.png`.

## Governance

Review the policy whenever iNeed introduces a new data category, processor, country,
payment flow, advertising feature, retention rule or data-subject request mechanism.
Production launch requires review by qualified legal counsel in the applicable markets.
